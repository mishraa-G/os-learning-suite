## 🚀 1-Click Launch (Easiest Way!)

### **Option 1: Double-Click from Finder (Mac)**
Simply double-click [`run.command`](file:///Users/divyanshmishra/Desktop/OS/run.command) in your Finder folder!
It will automatically open the Web UI in your browser and run the C++ simulation engine in a terminal.

### **Option 2: Terminal One-Liner**
Run this single command in terminal:
```bash
./run.sh
```
